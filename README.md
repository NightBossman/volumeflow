# VolumeFlow 🔊

**VolumeFlow** to nowoczesny mikser dźwięku dla systemu Windows, zbudowany w oparciu o technologię **Electron** i **Svelte 5**. Aplikacja pozwala na precyzyjne sterowanie głośnością pojedynczych procesów (aplikacji) oraz całego systemu w pięknym, przezroczystym interfejsie.

![VolumeFlow UI](https://raw.githubusercontent.com/NightBossman/volumeflow/main/screenshot_placeholder.png)

## ✨ Kluczowe Funkcje

*   **Prawdziwe sterowanie audio:** Kontrola głośności aplikacji w czasie rzeczywistym.
*   **Dual-Mode Interface:** 
    *   *Compact Mode:* Minimalistyczny panel z Master Volume i najważniejszymi procesami.
    *   *Expanded Mode:* Pełne centrum dowodzenia z listą wszystkich sesji audio.
*   **Premium Themes:** 4 unikalne motywy kolorystyczne (Midnight, Solar, Matrix, Frost).
*   **Eye Saver Mode:** Filtr redukujący niebieskie światło dla komfortu pracy w nocy.
*   **Glassmorphism UI:** Nowoczesna estetyka Acrylic/Mica z płynnymi animacjami.

## 🚀 Jak zacząć?

1.  Sklonuj repozytorium.
2.  Zainstaluj zależności: `npm install`.
3.  Pobierz [SoundVolumeView](https://www.nirsoft.net/utils/sound_volume_view.html) (x64) i umieść `SoundVolumeView.exe` w głównym folderze.
4.  Uruchom w trybie deweloperskim: `npm run dev`.

## 🛠️ Technologie

*   **Frontend:** Svelte 5 + Vite
*   **Backend:** Electron
*   **Ikony:** Lucide Svelte
*   **Mostek Audio:** SoundVolumeView (NirSoft)
